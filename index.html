Cloudflare Pages 绑定 KV 命名空间三步配置指南

  1. 登录 Cloudflare 控制台，进入左侧 Storage & Databases (或 Workers & Pages) → KV，点击 Create a namespace，名称填 project-schedule-kv。
  2. 进入你部署好的 Pages 项目 → Settings (设置) → Bindings (绑定 / Functions)，点击 Add (添加) → KV namespace。
  3. Variable name (变量名) 必须填写 SCHEDULE_KV，KV namespace 选择刚才创建的库并保存，最后在 Deployments 中点击 Retry deployment（或重新上传一次 public 文件夹）即可立即生效！
